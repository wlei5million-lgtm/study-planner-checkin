# 学习计划与打卡统计助手 MVP 范围

## 已实现

1. React + TypeScript + Vite 应用骨架。
2. 学习任务、科目、重复规则、计时会话等基础领域类型。
3. 日期格式化、重复规则展开、计时状态转换和统计聚合。
4. IndexedDB 本地数据库与仓储边界。
5. 平板优先的应用布局和四个主导航：首页、学习计划、数据统计、设置。
6. 每日任务创建、任务卡片展示、开始/暂停/完成计时。
7. 首页今日概览指标。
8. 各科用时统计图表和明细列表。
9. 科目展示、真实 JSON 备份文件下载与确认导入。
10. 多日期切换与直接日期选择。
11. 基础重复任务生成：每天、工作日、自定义星期。

## 暂未实现

1. 周/月日历视图。
2. 重复任务整组编辑。
3. 月度重复、艾宾浩斯复习周期。
4. 家长端、学生端账号体系和云同步。
5. 学习报告导出、提醒通知和成就激励。
6. 更细粒度的运动、娱乐和学习分类运营规则。

## 下一步建议

1. 为统计页增加周/月切换和完成率趋势。
2. 增加重复任务整组编辑和批量删除。
3. 增加 Playwright 端到端测试，覆盖创建任务、计时、统计和备份导入。
