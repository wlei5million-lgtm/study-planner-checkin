# 好学伴

面向学生日常学习的计划、打卡与统计 MVP。当前版本复刻产品的核心使用闭环：创建每日任务，按科目记录学习内容，开始/暂停/完成计时，并在首页和统计页查看学习投入。

## 功能范围

- 首页概览：展示当天学习时长、运动户外时长、任务完成数和完成率。
- 学习计划：创建当天学习任务，填写科目、内容和计划时长。
- 计时打卡：支持开始、暂停和完成任务，并累计实际学习时长。
- 数据统计：按科目展示累计用时，并提供基础柱状图。
- 设置与备份：查看科目列表，导出/导入本地 JSON 备份。
- 本地存储：使用 IndexedDB 保存科目和任务数据。

## 开发命令

```bash
npm install
npm test
npm run build
npm run dev
```

## 项目结构

```text
src/
  components/        通用布局和基础展示组件
  data/              IndexedDB、种子数据和仓储接口
  domain/            任务、日期、重复规则、计时和统计领域逻辑
  features/          首页、计划、统计、设置等业务页面
  test/              测试工厂与共享测试辅助
```

更多范围说明见 `docs/mvp-scope.md`。
